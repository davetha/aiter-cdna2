# Tuned W8A8 block-FP8 configs for MI210 (gfx90a)

vLLM looks for these by exact filename and warns when they are missing:

```
WARNING Using default W8A8 Block FP8 kernel config. Performance might be
    sub-optimal! Config file not found at ...device_name=AMD_Instinct_MI210...
```

Install by copying into vLLM's config directory:

```bash
cp *.json \
  /opt/python/lib/python3.14/site-packages/vllm/model_executor/layers/\
quantization/utils/configs/
```

Covers the four Qwen3-14B projection shapes (hidden 5120), at M = 1, 8, 32, 128,
512, 2048, 4096. vLLM picks the entry whose M is nearest the batch it is running.

Generated by `benchmarks/bench_fp8_fast_dequant_gfx90a.py`'s sweep, which checks
every configuration against a dequantized reference before timing it. Regenerate
for other shapes with the same script.

## These are tuned for the patched kernel

The winning configuration depends on which kernel consumes it, and these were
tuned against the bit-trick decode kernel installed by
`configs/enable_fast_fp8_dequant_gfx90a.py`. Without that patch they are still
valid and still better than vLLM's built-in default, just not optimal — the
stock kernel spends most of its time decoding FP8 rather than in the tile loop,
so its optimum sits elsewhere.

Tuning is worth ~3x on the stock kernel and ~1.8x on the patched one. The two
compose: stock+untuned is 1140 us at M=1 `qkv_proj`, patched+tuned is 112.5 us,
against bf16's 90.7. See [`docs/21`](../../docs/fp8-block-gemm.md).
